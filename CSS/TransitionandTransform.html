What's Happening?

  • Transform changes the element's appearance or position.
  • Transition makes the transform happen smoothly instead of instantly.

Try It Yourself!

Edit the CSS and observe the changes.

  • Change translateY(-30px) to -60px.
  • Change scale(1.3) to scale(2).
  • Change rotate(30deg) to rotate(180deg).
  • Change transition: transform 0.6s; to 2s.
  • Try combining multiple transforms, for example: 
    transform: scale(1.2) rotate(20deg);
